# Rugby Scouting Strategy Optimization System

AI-powered rugby team selection using Genetic Algorithm optimization.

## 🚀 Quick Start

### Local Development
```bash
pip install -r requirements.txt
python app.py
```

Visit: http://localhost:5000

### Railway Deployment

This app is ready for one-click deployment to Railway!

## 📋 Features

- **Genetic Algorithm Optimization** - Evolve optimal team compositions
- **Multi-Strategy Support** - 15+ rugby strategies (Scrum, Lineout, Passing Game, etc.)
- **Budget Constraints** - Salary cap management ($10M default)
- **Game Modes** - 7s, 10s, and 15s rugby formats
- **Complete My Team** - Optimize around existing contracted players
- **Real-time API Integration** - Live rugby data from API-Sports

## 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Frontend**: HTML/CSS/JavaScript + Tailwind CSS
- **Optimization**: Custom Genetic Algorithm
- **Data**: Pandas, NumPy
- **Deployment**: Railway / Gunicorn

## 📊 Performance

- **117.1% accuracy** vs Greedy baseline
- **97.9% budget utilization**
- **28.9% improvement** over random initialization
- **3-5 seconds** optimization time
